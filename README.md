# PaperLens — skill download

`paperlens-skill.zip` is the PaperLens skill packaged for upload in the Claude app (Customize → Skills → + → Upload a skill). It holds `paperlens/SKILL.md` and the Paper Reader tools in `paperlens/reader/`.

It is built from the `main` branch; see the [main README](https://github.com/yufchen723/PaperLens) for what PaperLens does and how it handles data.
